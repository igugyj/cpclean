# CompareCleaner

扫描项目中未被引用的文件，帮助您安全清理无用资源。

---

## 功能特性

- 扫描目标文件夹，找出未被任何参考文件引用的文件
- 通过 `.vscode/cpcleaner.jsonc` 自定义扩展名、排除目录、定界符
- 增量缓存：二次扫描仅处理变更文件，速度大幅提升
- 安全删除：文件移至回收站，可手动恢复
- 扫描过程可随时取消
- 自动读取 `.gitignore` 排除文件

---

## 快速开始

### 安装

从 VS Code 扩展市场安装，或使用 `.vsix` 文件手动安装。

### 打开面板

- 点击状态栏右下角的 `$(search) CPC`
- 或执行命令 **`CompareCleaner: Open Panel`**

### 首次使用

1. 确认 **扫描范围**（默认当前工作区）
2. 确认 **参考来源**（默认自动收集 `*.md`、`*.txt`、`*.rst` 等）
3. 点击 **执行筛选**
4. 查看未引用文件列表，双击可预览文件
5. 勾选要删除的文件，点击 **执行清理** 移至回收站

## 配置

配置文件位于 `.vscode/cpcleaner.jsonc`，支持 JSONC 格式（可写注释）。

如果文件不存在，点击界面上的 **配置** 按钮会自动生成模板。

### 配置项

| 字段                  | 类型                    | 默认值                                              | 说明                                                   |
| :-------------------- | :---------------------- | :-------------------------------------------------- | :----------------------------------------------------- |
| `referenceExtensions` | `string[]`              | `["md","txt","rst","html","tsx","css","py","json"]` | 参考文件扩展名（不带点）                               |
| `targetExtensions`    | `string[]`              | `["png","jpg","jpeg","gif","svg","ico","webp"]`     | 目标文件扩展名（不带点）                               |
| `excludeFolders`      | `string[]`              | `["node_modules","dist",".git","__pycache__"]`      | 排除的文件夹名称                                       |
| `pairs`               | `Record<string,string>` | 见下方                                              | 定界符配对，用于提取文件名                             |
| `scanRoot`            | `string`                | `""`                                                | 扫描根目录（相对工作区）；空字符串表示使用工作区根目录 |
| `allowExternalScan`   | `boolean`               | `false`                                             | 是否允许扫描工作区外的目录                             |

### 默认定界符

```json
"pairs": {
  "(": ")",
  "\"": "\"",
  "'": "'",
  "`": "`",
  "[": "]",
  "<": ">"
}
```

### 配置示例

```json
{
  "referenceExtensions": ["md", "txt", "rst", "adoc"],
  "targetExtensions": [
    "png",
    "jpg",
    "jpeg",
    "gif",
    "svg",
    "ico",
    "webp",
    "mp4"
  ],
  "excludeFolders": ["node_modules", "dist", ".git", "__pycache__", "vendor"],
  "pairs": {
    "(": ")",
    "\"": "\"",
    "'": "'",
    "`": "`",
    "[": "]",
    "<": ">"
  },
  "scanRoot": "",
  "allowExternalScan": false
}
```

## 匹配规则

如果文件名出现在任一参考文件中，即视为“已引用”。匹配方式有以下两种：

### 1. 定界符提取（精确匹配）

从参考文件中提取被配对定界符包围的完整文件名（含扩展名）。

**示例**：

| 参考文件内容        | 匹配结果    |
| :------------------ | :---------- |
| `(assets/logo.png)` | `logo.png`  |
| `![alt](photo.jpg)` | `photo.jpg` |
| `"image.svg"`       | `image.svg` |

### 2. 全局文本包含（兜底匹配）

如果定界符未能匹配，会直接在整个参考文件内容中搜索文件名，用于处理无定界符的引用。

**示例**：

```yaml
- assets/banner.png
- assets/icon.svg
```

以上两种方式会合并结果：只要文件名出现在任一参考文件中，即视为“已引用”。

> 仅匹配文件名（含扩展名），不匹配路径。例如 `assets/logo.png` 和 `images/logo.png` 都会被识别为 `logo.png`。

## 操作指南

| 操作         | 说明                                      |
| :----------- | :---------------------------------------- |
| **扫描范围** | 默认当前工作区，可手动添加/移除多个文件夹 |
| **参考来源** | 默认自动收集，也可手动添加/移除特定文件   |
| **执行筛选** | 开始扫描，支持取消                        |
| **移除选中** | 从列表中移除选中的文件（不删除物理文件）  |
| **清除列表** | 清空所有未引用文件列表                    |
| **清理缓存** | 删除增量缓存文件，下次扫描重新全量分析    |
| **执行清理** | 将选中的文件移至回收站（可恢复）          |
| **双击文件** | 在 VS Code 中打开文件预览                 |
| **重置**     | 恢复所有状态到初始值                      |
| **配置**     | 打开 `.vscode/cpcleaner.jsonc` 配置文件   |

## 注意事项

- 清理的文件将移至系统**回收站**，可手动恢复
- 建议在清理前仔细审核列表，避免误删
- 配置文件格式错误时会自动回退默认配置并给出提示
- 外部目录扫描默认被阻止，需设置 `allowExternalScan: true`
- `.gitignore` 中的文件会自动排除（扫描范围和参考来源均生效）

---

## 技术细节

- **目标文件收集**：递归遍历扫描目录，根据 `targetExtensions` 过滤
- **参考文件收集**：递归遍历工作区，根据 `referenceExtensions` 过滤，遵循 `.gitignore`
- **缓存机制**：存储文件的 `mtime`、`size`、`isReferenced`，二次扫描仅处理变更文件
- **并发控制**：单线程递归，取消信号（`AbortSignal`）支持安全中断
- **错误处理**：权限不足或其他错误时跳过目录，不影响整体扫描
